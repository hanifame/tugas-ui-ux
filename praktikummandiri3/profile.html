Nama saya Hanif Al Ghifari, saya salah satu mahasiswa dari STT Terpadu Nurul Fikri dengan prodi Teknik Informatika. Saya memilih prodi Teknik Informatika karena ingin melanjutkan jurusan saya sewaktu SMK . Saat ini saya sedang belajar untuk membuat web biodata menggunakan HTML dan CSS.


Selama saya mempelajari mata kuliah desain UI/IX dan pemrograman web memiliki beberapa kendala, diantaranya saya suka lupa fungsi dari suatu kode dan bingung untuk mengatur layout dari sebuah elemen. Hal tersebut dapat terjadi karena saat SMK pelajaran yang difokuskan oleh sekolah saya yaitu di bidang jaringan bukan di pemrograman web. Saat saya lulus dari SMk saya berhasil mendapatkan sertifikat MTCNA dan pernah mengikuti perlombaan di bidang jaringan berbasis kabel, dari perlombaan tersebut saya berhasil mendapatkan juara 1 tingkat kota dan juara 16 tingkat provinsi. Untuk saat ini saya memiliki minat dan ketertarikan di mata kuliah dasar dasar pemrograman.
